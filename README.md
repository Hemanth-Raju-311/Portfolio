# Hemanth Raju - Portfolio

A creative, interactive, and playful portfolio showcasing my work as an AI & ML Engineer. Built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Interactive Doodle Design**: Hand-drawn aesthetic using custom CSS border-radii and box-shadows.
- **Dynamic Animations**: Spring-based physics and hover effects using Framer Motion.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop devices.
- **Performant**: Built purely on modern frontend technologies without any bulky backend requirements.

## Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

To run this project locally, ensure you have Node.js installed, then execute the following commands:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit `http://localhost:3000` to view the application in your browser.

## Deployment

This portfolio is entirely static and can be deployed easily on platforms like Vercel, Netlify, or GitHub Pages.

```bash
# Build the production bundle
npm run build
```
